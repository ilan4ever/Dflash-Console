## DFlash Console 0.3.103

### Highlights
- Gemma and Qwen vision projectors (mmproj) for image/OCR workloads

Download `DFlash-Console-Setup-0.3.103-x64.exe` below. Requires Windows 10+, Python 3.10+, and PowerShell 7+ for the Console data root.
