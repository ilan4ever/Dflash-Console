# Settings — Appearance

Appearance preferences are not exposed as a separate Settings panel in the
current build. DFlash Console uses its dark, compact desktop layout in both the
browser and Electron shell.

The sidebar can collapse automatically on narrow screens, and the main layout
stacks the runtime inspector below the content when the viewport is small.
Theme, language, typography, and chat-style controls remain future work and
should not be presented as supported configuration.
