# Settings — Model storage and locations

The current Settings view focuses on local workspace configuration. There is no
in-app update channel or account system.

## Model storage

- Enabled model library folders
- Scan enable/disable per library
- Default Hugging Face download folder
- Add, remove, link, copy, or move model folders into a library

## Locations

The Locations panel is read-only for paths and shows:

- Console configuration file
- DFlash root
- Model library and default download folder
- Engine logs
- Launch presets
- Loopback UI URL

It also provides config and preset import/export actions. Imported files are
validated by the backend and require confirmation.
