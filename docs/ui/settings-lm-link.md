# Settings — Remote nodes

Remote nodes are configured on the **Nodes** sidebar tab (not in Settings).

v1 supports manual registration of another DFlash Console base URL, health checks, and
a test chat proxy. See [nodes-v1-plan.md](./nodes-v1-plan.md) for the full roadmap.

Future work: authenticated pairing, encrypted transport, trusted-device management, and
workload routing from Engines / Playground.
