## DFlash Console 0.3.106

### Highlights
- **Desktop app fix:** installed shell no longer fights a newer API on the same data folder (invisible window / zombie processes)
- Clicking the shortcut again recovers the main window if boot finished without showing it

### Install
- **Windows:** `DFlash-Console-Setup-0.3.106-x64.exe` from GitHub Releases
- **CLI:** `pip install dflash-console` then `dflash serve`

Requires Windows 10+, Python 3.10+, and PowerShell 7+ for the Console data root.
