## DFlash Console 0.3.129

### Test release — automatic updates

This release is a follow-up test for installed DFlash Console 0.3.128
applications. The desktop shell should detect this newer signed GitHub release
and show the update prompt automatically.

No model or engine behavior changes are included.

### Install

- **Windows:** `DFlash-Console-Setup-0.3.129-x64.exe` from GitHub Releases
- **CLI:** `pip install dflash-console==0.3.129`
