## Source and binaries

If you distribute a DFlash Console executable, installer, or other
non-source form, review the AGPL requirements for providing the corresponding
source. The corresponding source includes the project material needed to
build, install, run, and modify the covered work, subject to the AGPL's
definitions and exclusions.

The official release process publishes source and build information alongside
Windows artifacts. A downstream distributor is responsible for meeting the
AGPL obligations for its own modified distribution.

## Network use

The Console exposes local HTTP APIs and is designed for loopback use. If a
modified version is operated so users interact with it remotely over a
network, review AGPL section 13 and provide the corresponding-source offer
required by the license.
