## DFlash Console 0.3.117

### Highlights
- Automatic, architecture-aware DFlash draft discovery, validation, registration, and attachment
- Correct chat routing and vision/projector readiness for DFlash model stacks
- FreeToken support for large Hugging Face models, including paging-file guidance and live expert-loading progress
- Engines view improvements for model status, progress, cleanup, and loaded-model visibility
- Clearer model loading errors, memory checks, and runtime diagnostics

### Install
- **Windows:** download `DFlash-Console-Setup-0.3.117-x64.exe` from GitHub Releases
- **Portable:** download `DFlash-Console-Portable-0.3.117-x64.exe`
- **CLI:** `pip install dflash-console` then `dflash serve`

Requires Windows 10+, Python 3.10+, and PowerShell 7+ for the Console data root.
