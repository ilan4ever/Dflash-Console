## DFlash Console 0.3.105

### Highlights
- Documentation aligned for public preview (GitHub Releases + PyPI + in-app About/Docs)
- `pip install dflash-console` on PyPI; `dflash serve` stops foreign Console instances on port 8900
- Gemma/Qwen vision projectors, split-GGUF import, accelerator filtering on Models tab

### Install
- **Windows:** `DFlash-Console-Setup-0.3.105-x64.exe` from GitHub Releases
- **CLI:** `pip install dflash-console` then `dflash serve`

Requires Windows 10+, Python 3.10+, and PowerShell 7+ for the Console data root.
