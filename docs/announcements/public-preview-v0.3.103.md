# DFlash Console v0.3.103 — public preview testers wanted

We're opening DFlash Console for early testing on real Windows machines.

## What it is

A local control panel for **DFlash speculative-decoding stacks** and a unified model runtime — engines, models, Hugging Face downloads, Piper TTS, Whisper STT, embeddings, and a `dflash` terminal CLI.

## Install (Windows)

1. **Recommended:** download **`DFlash-Console-Setup-0.3.103-x64.exe`** from [Releases](https://github.com/ilan4ever/Dflash-Console/releases/tag/v0.3.103).
2. Requires **Windows 10+**, **Python 3.10+**, and **PowerShell 7+** for the Console data root.
3. Open **http://127.0.0.1:8900/** after install (or use the desktop app).

**Terminal CLI (optional):** `pip install dflash-console` then `dflash serve`.
