# DFlash Console support

Install with `pip install dflash-console` then `dflash serve`, or use the
Windows installer. The terminal command is `dflash` (list, chat, embed,
delete, nodes, settings). Docs:
[User guide](https://onevoiceai.in/dflash-console/docs/USER-GUIDE.md) and
[CLI](https://onevoiceai.in/dflash-console/docs/CLI.md).

## Ask a question

Use [GitHub Discussions](https://github.com/ilan4ever/Dflash-Console/discussions)
for setup questions, model-library questions, usage advice, and general
feedback. Search existing discussions before starting a new thread.

## Report a bug

Use the [bug report form](https://github.com/ilan4ever/Dflash-Console/issues/new?template=bug_report.yml).
Include:

- Console version from the **About** page
- Windows, Python, PowerShell, and Node.js versions
- The steps that reproduce the problem
- Expected and actual behavior
- Relevant redacted logs

Do not attach model weights, `config.json`, access tokens, private logs, or
other credentials.

## Request a feature

Use the [feature request form](https://github.com/ilan4ever/Dflash-Console/issues/new?template=feature_request.yml)
for proposed changes. Explain the user problem and the workflow the feature
should improve.

## Report a security issue

Do not use a public issue or discussion for a vulnerability. Follow
[SECURITY.md](./SECURITY.md) and GitHub's private vulnerability reporting
process instead.
